Theorem 3.5.15.

Following conditions are equivalent for a nonzero semisimple \(A\)-module \(M\text{.}\)
  1. The module \(M\) is finitely generated as an \(A\)-module
    🔗
    🔗
  2. The module \(M\) is direct sum of finitely many simple modules.
    🔗
    🔗
  3. The module \(M\) is Artinian.
    🔗
    🔗
  4. The module \(M\) is Noetherian.
    🔗
    🔗
  5. There exists \(m<\omega\) such that if \(M_0\subsetneq M_1\subsetneq\cdots\subsetneq M_k\) is finite then, \(k\leq m\text{.}\)
