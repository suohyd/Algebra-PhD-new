Worksheet Exercise 2.

Let \(f\colon M\to M\) be an \(A\)-module endomorphism.
  1. Show that if \(M\) is Artinian then, \(\Image{f^n}+\ker f^n=M\) for some positive integer \(n\text{.}\) Use this to show that \(f\) is an isomorphism if and only if it is a monomorphism.

    🔗
